## Pro2+ v1.0.0

Pro2 手柄的 Windows 全功能适配，绿色单文件，双击即用。

### 下载

| 版本 | 文件 |
| :-- | :-- |
| 中文界面 | `Pro2Plus-1.0.0.exe` |
| English UI | `Pro2Plus-1.0.0-en.exe` |

### 连接方式

- **蓝牙**：先点软件里的「连接」按钮，再长按 Pro2 手柄的配对键 2 秒，等状态变成「已连接」。
- **有线**：USB-C 直连，插上自动连接。

### 本版内容

- 有线 500Hz / 蓝牙 125Hz 双通道，状态栏实时显示实际回报率
- Pro1 / Xbox / PS5 / 键鼠 四种虚拟输出模式（Pro2 手柄作为输入）
- 键鼠映射：手柄按键映射键盘、鼠标左右键与滚轮，摇杆映射 WASD
- 陀螺仪映射右摇杆、陀螺仪映射鼠标（满速 DPS / 水平竖直倍率 / 下压倍率可调）
- PS5 / Pro1 原生体感透传，游戏内原生陀螺仪直接可用，灵敏度可单独调
- 体感映射开关绑在 Pro2 手柄的 C 键（聊天键），游戏内按一下即可开关
- 摇杆零位与行程校准、陀螺仪校准，有线/蓝牙死区分开保存
- 按键时序：双击间隔、长按判定、组合键前后顺序
- 震动强度 0–200%，HD 震动回传

### 首次运行

exe 内置 USBIP 驱动安装包，首次启动会弹一次管理员确认，安装完成后即可使用，不需要联网。
系统要求：Windows 10 19041+ / Windows 11，不需要单独安装 .NET 运行时。
